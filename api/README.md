# Отправка заявок

Получатель: manufactura_tm@mail.ru. Покупателю письма не отправляются.

Разместить сайт на хостинге с PHP 8+ и HTTPS. Настроить почтовый транспорт PHP mail() и переменную окружения MANUFACTURA_MAIL_FROM: адрес отправителя на домене сайта. SPF/DKIM настроить через почтового провайдера/хостинг. Без адреса отправителя обработчик возвращает503, успешную отправку не имитирует.

GET /api/request.php возвращает CSRF-токен с сессионной cookie. POST принимает JSON, проверяет контакты, согласие, модель, каждый размер и количество, цвет и покрытие. Есть honeypot, ограничение частоты в сессии, защита от повторной обработки requestId. Перед публикацией проверить доставку настоящего тестового письма и настроить ограничение запросов на уровне хостинга.

Локальный статический просмотр на порту 4173 не исполняет PHP: отправка там намеренно отключена. 11.11.2026 обработчик прошёл PHP lint; фактическая доставка письма на рабочем хостинге в этом аудите не проверялась. mail()=true означает принятие письма почтовым транспортом, а не гарантию попадания во входящие.

При интеграции на WordPress подключить его почтовую инфраструктуру и единый адрес обработчика на всех страницах. Сейчас на главной задан /api/request.php, а на privacy.html и consent.html адрес пустой; формы юридических страниц пока сообщают о недоступности отправки. Не переносить этот временный разнобой в тему.

Временные базовые RAL находятся в index.html в select[name=color]; заменить после получения списка заказчика. Цвет, покрытие и сетка общие для всех строк выбранной модели; каждая строка содержит свои размеры и количество, максимум20 строк.
